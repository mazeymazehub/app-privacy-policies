# Apps des Westend-Drachen Horts

Interne iOS-Apps für das Team des Grundschulhorts Westend-Drachen (Elterninitiative e.V., München). Die Apps sind nur mit einem Konto des Horts nutzbar; Konten vergibt der Hort.
